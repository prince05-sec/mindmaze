# MindMaze

**AI-powered mental wellness companion**

---

## 🌟 Overview

MindMaze is an AI-driven mental wellness application designed to help users track, understand, and improve their emotional and cognitive well‑being. Through smart insights, gamified cognitive exercises, and mood analytics, MindMaze creates a personalized mental health journey for every user.

---

## 🚀 Key Features

* 🧠 **AI Mood Analysis** – Understand emotional patterns with intelligent insights.
* 📊 **Daily Mood Tracking** – Simple, intuitive logging backed by visual analytics.
* 🎮 **Gamified Mental Exercises** – Engage in brain‑training tasks for focus, memory, and calmness.
* 🔔 **Smart Reminders** – Stay consistent with mindfulness and journaling.
* 🔒 **User Privacy First** – No data sharing, everything stored securely.

---

## 🧩 Tech Stack

* **Flutter** (Dart) – Frontend & UI
* **Provider / Riverpod** – State management
* **Firebase / Supabase** – Backend services (auth, storage, DB)
* **TensorFlow Lite / Custom ML models** – For AI mood interpretation

## 🧠 Architecture Overview

MindMaze follows a clean architecture approach:

* **UI Layer** – Screens, widgets, themes
* **State Layer** – Provider / Riverpod for state handling
* **Domain Layer** – Models, business logic
* **Data Layer** – API, Firebase, ML handlers
